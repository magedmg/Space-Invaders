# Space Invaders using Raylib C++

A Space Invaders game done for fun using Raylib and C++.

## Overview

This project is a basic implementation of the classic Space Invaders game using the [Raylib](https://www.raylib.com/) library in C++. It was developed purely for fun and to explore game programming concepts.

## Getting Started

### Prerequisites

- **Raylib:** Make sure you have [Raylib](https://www.raylib.com/) installed.
- **C++ Compiler:** A C++ compiler such as g++ or clang++.
- **Make:** GNU Make is used to build the project.

### Building the Project

1. **Clone the Repository:**

   ```bash
   git clone https://github.com/yourusername/space-invaders-raylib.git
   cd space-invaders-raylib
   ```

2. **Build:**
   Simply run:
      ```bash
   make
```
